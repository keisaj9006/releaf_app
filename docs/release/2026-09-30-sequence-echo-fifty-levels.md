# Sequence Echo 50-level progression — 30 September 2026

Sequence Echo is the first formerly 12-level Brain game with playable profiles through level 50. The live cap is raised only for `sequence_echo`; Memory and Labyrinth retain their existing 50-level paths, while the other 12 registered games remain capped at 12. Stored completion counts map to the newly earned level without migration; the existing two-completions-per-level rule, rewards, route and game ID are unchanged.

The resolver reproduces every level-1–12 round count, sequence length, flash duration and deterministic cell order for Easy, Medium and Hard. Levels 13–50 add deterministic per-level patterns with bounded 7–18-cell sequences, 7–12 rounds and 145–560 ms flashes. A narrow 320 dp widget test opens level 50, plays its first sequence and accepts the correct input. A host test loads 98 stored completions and displays level 50. Automated checks cover every higher level and difficulty, no immediate duplicate cell, and distinct parameters across challenge bands. Physical playability and accessibility at higher levels remain for device QA; this checkpoint is not owner approval of game feel.
