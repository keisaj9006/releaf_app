# N-back 50-level progression — 30 September 2026

N-back now has a playable, bounded profile through level 50. Its live cap is raised only for `n_back`; Memory, Labyrinth and Sequence Echo already have 50-level paths, while the other 11 registered games remain capped at 12. The existing game ID, route, stored completion count, two-completions-per-level rule, score/reward flow and access remain unchanged. Existing cumulative completions reveal their earned level without migration.

For levels 1–12, the resolver pins the prior N depth, trial count, random seed and 0.34 match chance for all three difficulties. Levels 13–50 increase session load in five challenge bands while limiting depth to four and trials to 18–38. The generated sequence still uses the same deliberate match-versus-different interaction. Automated tests cover every higher level and difficulty, distinct band parameters, unaffected Rule Shift cap and a level-50 N-back screen advancing on a 320 dp viewport. Physical-device playability, comfort and accessibility at higher levels remain unverified.
